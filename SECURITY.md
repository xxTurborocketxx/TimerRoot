# Security Policy

## Supported versions

Only the latest stable release line receives updates. Pre-releases
(beta channel) are for testing and are not supported.

## Reporting a vulnerability

Use GitHub's **private vulnerability reporting** (Security tab →
"Report a vulnerability"). Please do not open a public issue about
an exploitable weakness; give a fix a chance to land first.

Include: device model, firmware build number, app version, and the
exact steps or logs that reproduce the problem.

## Scope

This is a research/root tool for devices you own. Reports about the
exploit core, the app, or the release pipeline are welcome.
